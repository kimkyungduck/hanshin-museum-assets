# museum-cdn

HANSHIN MUSEUM(ducking.co.kr/projects/museum) 의 무거운 파일 — 재질 · 나무 · 사람 · 소리.
jsDelivr 가 이 저장소를 무료로 배포한다: `https://cdn.jsdelivr.net/gh/<계정>/<저장소>@<태그>/assets/...`

- 사이트 쪽 설정: museum/index.html 의 `window.MUSEUM_CDN = '...'` 한 줄
- 파일을 바꾸면 **새 태그**를 달고(예: v2) MUSEUM_CDN 의 @태그도 바꾼다(jsDelivr 는 태그별로 오래 캐시한다)
- 출처: Poly Haven(CC0) · MakeHuman(CC0) · Kenney · OpenGameArt(CC0)

- Remy(Mixamo 캐릭터)는 재배포할 수 없어 이 저장소에 두지 않는다 — 사이트(카페24)에서 직접 받는다
